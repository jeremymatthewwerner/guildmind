# 2026-07-31 Build-Plan Audit and Disposition Ledger

**Status:** Current through the 2026-08-03 Stage 1 hardening checkpoints; Stage 1 gate not passed<br>
**Sources:** Benchmark/corpus review, runtime/evidence review, and search/statistics/judge review

This ledger preserves the substantive review findings and where they landed. It distinguishes a plan change from working software:

- **Plan-incorporated:** the staged build plan now carries the requirement.
- **Specified-this-slice:** Experiment 0001, the threat model, or an ADR makes the requirement executable. This does **not** mean runtime code exists.
- **Implemented—initial slice:** code and tests exist for the narrow scope linked in the row; it does not waive a later container, security, scale, or campaign gate.
- **Partially implemented—hardening checkpoint:** some executable control or recovery evidence exists, but the reference-host or end-to-end gate remains open.
- **Deferred—Stage N:** deliberately belongs to a named later gate.
- **Open owner decision:** Stage 0 cannot close until a named choice is made.
- **Open implementation:** accepted design with code/tests still required.

## Closure summary

The accepted design findings above are represented in the build plan or a linked implementation checkpoint according to each row's status. The 2026-08-01 through 2026-08-03 hardening work provides partial runtime, resource, patch-intake, evaluator-corpus, evaluator-containment, atomic CAS-publication, guarded-recovery, cooperative-maintenance, resumable-quarantine, and one-fixture reliability-harness evidence but does not pass the Stage 1 sandbox gate. The local CAS process-kill and same-digest contention sequences plus the quarantine process-kill/cooperative-concurrency matrix are complete, and the campaign contract/CLI has passed its one-attempt development smoke. Reference-host/worker containment, runtime-level and hostile same-UID/open-process stress, provider idempotency, the distinct 20-fixture × 5-round campaign, broader analyses, search calibration, hybrid controller learning, and judge systems remain open or deferred to their named gates. The four unresolved Stage 0 owner choices are the model, spend ceilings, `δ`, and evidence/publication level in [Experiment 0001](../experiments/0001-institutional-search.md#3-owner-decisions-required-before-stage-0-exit).
